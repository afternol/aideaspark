# トレンドレポート品質チェックリスト

AideaSpark TrendCacheレポートの第8〜12回監査（累計129件修正）から導出した、
作成・レビュー時の必須チェックリストと高付加価値化のポイント。

---

## 1. ファクト精度チェックリスト（1件でも誤りがあればアウト）

### 1-1. 数値・金額
- [ ] 桁が正しいか（億 vs 兆、million vs billion）
  - 例：音楽テック市場 25.12億ドル → 251.2億ドル（10倍桁違い）
  - 例：デジタルツイン 24.48億ドル → 244億8,000万ドル（$24.48 billionの誤表記）
- [ ] 調達金額が「ラウンド合計」か「株式部分のみ」かが明確か
  - 例：Findem $51M = シリーズC $36M + J.P. Morganデット $15M（「シリーズC$51M」は誤り）
- [ ] xAI・Anthropicなどの非公開内訳を断言していないか
- [ ] 市場規模の数値が「グローバル市場」か「日本市場」か「細分市場」かを明示しているか
  - 例：画像生成AI市場ではなく「生成AI全体」の数値を使っていないか
- [ ] CAGR計算が数学的に正しいか（終点/始点）^(1/年数) - 1、誤差5%超は修正

### 1-2. 日付・時期
- [ ] 法律・規制の施行日が正確か
  - 例：メンタルヘルス ストレスチェック義務化「2026年4月」→「2028年5月前後見込み」
  - 例：電子帳簿保存法「2026年1月義務化」→「2024年1月」
- [ ] 調達・M&A・上場の発表日と実行日を混同していないか
  - 例：KINS調達「2024年10月」→「2024年7月2日」
  - 例：freee在庫管理「2026年4月16日」→「2026年4月15日（16日はAgent Hub発表）」
- [ ] 制度の「助走・算定期間」と「本格稼働」を混同していないか
  - 例：GX-ETS「2026年度本格稼働」→「2026年度は算定・届出期間、本格取引は2027年秋頃」
- [ ] 株式市場イベントで「初値」と「終値」を混同していないか
  - 例：PayPay上場「初日終値19%高」→「初値19%高、終値13.5%高」
- [ ] recentNewsの日付が「発表時点」か「施行時点」か「報道時点」か明確か
- [ ] 古い情報が最新として掲載されていないか（2020〜2022年の情報に特に注意）

### 1-3. 企業・人名
- [ ] 企業名の正式名称が正しいか
  - 例：「損保ジャパンHD」→「SOMPOホールディングス」
  - 例：「Thinkings買収」で「ビズリーチ」→正しくはVisionalグループ
- [ ] 存続していない企業を現役扱いしていないか
  - 例：UUUM（2025年2月17日上場廃止）
- [ ] 似た企業名・業種の混同がないか
  - 例：ヤンマー（近距離監視）とクボタ（遠隔監視・日本初）の混同
- [ ] 出資者・投資家が正確か（投資タイミングの確認必須）
  - 例：ElevenLabsの出資者でSequoiaが早期ラウンドから参加と誤記
- [ ] 役職・肩書きが現時点で正確か（前職・前CEOでないか）

### 1-4. 技術・事実
- [ ] 「世界初」「日本初」の記述に根拠があるか
- [ ] 定量的な効果（「40%向上」「45%の開発者が活用」等）に一次ソースがあるか
  - 未確認の数値は削除すること
- [ ] 国籍・設立地が正確か（投資家国籍と企業国籍を混同しないこと）
  - 例：Vesta = 米国シリコンバレー設立（中国VCから出資を受けるが米国企業）

## 2. 内容整合性チェックリスト（各トレンドキーワードに整合した内容か）

### 2-1. keyPlayers
- [ ] 掲載企業が**そのトレンドの主要事業者**か（別業界の企業が混入していないか）
  - NG例：モビリティに「インターステラテクノロジズ（宇宙ロケット）」
  - NG例：API/BaaSに「ALPHA（VCファンド）」
  - NG例：コンテンツに「経済産業省（政府機関）」
  - NG例：ヘルスケアに「三菱商事Aethon（天然ガス事業）」
- [ ] 3〜5社が揃っているか（2社のみは不十分）
- [ ] 調達・提携・サービス名など最新動向が記載されているか

### 2-2. recentNews
- [ ] **全10件がそのキーワードのトレンドに直接関連するニュースか**
  - NG例：クリエイターエコノミーに「Mujin（ロボット企業）の調達情報」
  - NG例：ヘルスケアに「製薬会社の非デジタルM&A情報」
- [ ] 古い情報（1年超前）が混入していないか
- [ ] 日付が新しい順に並んでいるか
- [ ] headlineが30字以内・具体的な企業名や数値を含むか

### 2-3. globalContext
- [ ] 海外（米国・欧州・アジア）の情報がそのトレンドに固有の内容か
  - NG例：一般的なAI規制・AI法の話のみ
  - NG例：全く別分野の海外企業の話
- [ ] 「日本市場への影響・示唆」が含まれているか
- [ ] 具体的企業名・数値・政策名が含まれているか（抽象論は不可）

### 2-4. investmentTrends
- [ ] 投資動向がそのトレンド分野の企業・ファンドへの投資か
  - NG例：ファンコミュニティに「ロレアル（D2C文脈）の投資」
  - NG例：エネルギーテックにロケット企業の調達情報
- [ ] 金額・ラウンド・投資家名・日付が含まれているか

### 2-5. marketSize
- [ ] 引用している市場規模がそのトレンドの**専用市場**か（上位概念市場でないか）
  - NG例：「画像・動画AI」市場規模として「生成AI全体」の数値を使用
  - NG例：「サーキュラーエコノミー」市場として「コンサルティング市場」のみ掲載
- [ ] 調査会社名・発行年月が明記されているか
- [ ] グローバル市場と日本市場が混在していないか（明確に区別されているか）

### 2-6. sources
- [ ] そのトレンドに無関係なサイトが出典になっていないか
  - NG例：ECマーケットプレイスの出典に「日銀（boj.or.jp）」「株式情報サイト」
- [ ] URLが正しいフォーマット（https://で始まるか）か
- [ ] 本文中で引用した番号がsourcesに全て存在するか（欠番がないか）
- [ ] sourcesに存在するが本文中で一度も引用されていない番号がないか（sources過多）
- [ ] 本文中の引用番号がsourcesの最大番号を超えていないか（範囲外参照）
  - 例：sources 8件なのに本文に[10]が存在 → 範囲外参照
- [ ] sourcesのURLが実際のページと対応しているか（古い記事URLに最新数値を紐付けていないか）
  - 例：2020年のESG記事URLに2024年度データを紐付け

## 3. 高付加価値化のポイント

### 3-1. summary（冒頭サマリー）の品質
**良い例**：「2026年4月時点で日本の生成AI市場は急拡大しており、Sakana AIが累計520億円・評価額約4,000億円[3]を達成。政府のAI戦略2025に基づく国内投資加速と、AnthropicのシリーズG総額300億ドル[1]が牽引するグローバル競争が日本市場にも波及している。」

チェック項目：
- [ ] 数値・企業名・時期が3つ以上含まれるか
- [ ] 引用番号が付与されているか
- [ ] 「〜が注目されている」「〜が期待される」だけで終わっていないか

### 3-2. outlook（見通し）の品質
**良い例**：「2026年秋のGX-ETS本格施行と2027年3月期からのSSBJ開示義務化（時価総額3兆円以上）が分水嶺となり、企業のGX対応投資が加速する見通し。」

チェック項目：
- [ ] 具体的なマイルストーン（日付・企業名・制度名）が含まれているか
- [ ] 12〜18ヶ月以内の出来事にフォーカスしているか
- [ ] 「さらなる成長が期待される」のみで終わっていないか

### 3-3. 日本固有性の担保
- [ ] 日本市場の具体的な規制・政策動向が含まれているか
- [ ] 日本企業の固有事例（調達・提携・上場）が含まれているか
- [ ] グローバル情報だけで日本への言及が薄くなっていないか

### 3-4. 引用の品質
- [ ] 一次ソース（公式発表・政府統計・主要経済紙）を最優先しているか
- [ ] 二次ソース（まとめサイト・ブログ）のみに依存していないか
- [ ] 引用番号が文中の該当箇所の直後に置かれているか（段落末ではなく文末）

## 4. 生成AIレポート作成時のプロンプトルール

### 4-1. 削除すべき記述パターン
| パターン | 理由 |
|---------|------|
| 「〜が見込まれる」のみのoutlook | 具体性ゼロ |
| 「業界全体で〜」「多くの企業が〜」 | ファクトなし |
| 「前月比大幅増」（数値なし） | 曖昧すぎ |
| 「世界初」「業界初」（根拠なし） | ハルシネーションリスク |
| 「〜が発表した」（日付なし） | 時制不明 |
| 「配送効率40%向上」（一次ソース未確認） | 削除対象 |

### 4-2. 確認困難な情報の扱い
- 一次ソースで確認できない定量的な記述は**削除**する
- 「〜との報道がある」等の断定回避表現は使わない（事実として書くか削除するか二択）
- 数値の断定が難しい場合は「約〜」「〜前後」と明記する

### 4-3. 特に注意が必要なカテゴリ
| カテゴリ | 注意ポイント |
|---------|------------|
| AI/ML全般 | 調達額・評価額の更新頻度が高い。最新情報を必ず確認 |
| 規制・政策 | 「施行日」と「発表日」「義務化完全適用日」を厳密に区別 |
| 市場規模 | グローバル/日本/細分市場を混同しやすい。出典の定義を確認 |
| CAGR | 期間の始点・終点を誤りやすい。計算式で数学的検証必須 |
| 上場・廃止 | 上場廃止・買収後の企業を現役扱いしないこと |
